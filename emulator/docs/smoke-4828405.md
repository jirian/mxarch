# First L40S smoke run (2026-11-05)

Source: `slurm-avant-garde-smoke-4828405.out` and
`runs/smoke-4828405/gpt2-smoke.json` under the artifact data root.

GPT-2 Small, WikiText-2 validation: 32 windows of 128 tokens, 4,064 scored
transitions, both weights and activations quantized.

| Mode | Perplexity |
| --- | ---: |
| FP32 | 57.678035 |
| Hierarchical MX9 | 58.234839 |
| Flattened MX9 | 60.952380 |
| Lossless flattening control | 58.234839 |

Hierarchical and lossless controls match exactly. Default flattening recorded
187,184,333 rounding changes and 7,961,577 nonzero codes rounded to zero,
with zero out-of-range or saturated flattened codes. Counts combine cached
weight conversions and activation conversions over the run, not unique weights.
The tiny random ViT GPU test also completed.

This short run establishes that the numerical path works on L40S and suggests a
flattening penalty in this reconstruction. It does not establish a model-size
trend, a reasoning-horizon effect, or fidelity to the authors' unpublished
rounding choices. Pretrained ViT/ImageNet accuracy has not yet been evaluated.
